# GS1 Output

This folder contains generated files, separated by whether the user normally
edits/uses them or they are implementation details.

User-facing files:

- `ukrainian_translation.json` — active editable translation file generated/opened by option 2.

Subfolders:

- `Rom/` — timestamped final ROMs for testing/playing.
- `missing_glyphs/` — extracted editable font bins/metadata and font-injection test ROMs.
- `json_splitter_parts/` — translation chunks created by the split option.
- `temp/` — intermediate ROMs, reports, dumps, generated templates, and temporary working files that normally do not need manual editing.
